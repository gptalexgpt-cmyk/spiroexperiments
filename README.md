# Spiro Experiments (Unity 3D)

Учебный Unity-проект для исследования перспективного отображения пространственных кривых на основе формул спирографа (эпитрохоида).

## Что внутри

- `Assets/Scripts/Spirograph3DGenerator.cs` — генерация 3D-кривой спирографа через параметры `R`, `r`, `d`, а также модуляцию по оси `Y`.
- `Assets/Scripts/OrbitCameraController.cs` — орбитальная камера (ПКМ для вращения, колесо мыши для зума).
- `Assets/Scripts/PerspectiveGridGizmo.cs` — вспомогательная сетка в сцене (Gizmos), чтобы удобнее изучать перспективу.
- `Assets/Scripts/SpiroStudyBootstrap.cs` — авто-настройка базовой сцены при запуске, если в сцене ещё ничего нет.

## Формула

Используется эпитрохоида (в плоскости XZ):

- `x = (R + r) cos(t) - d cos((R + r)/r * t)`
- `z = (R + r) sin(t) - d sin((R + r)/r * t)`

И добавляется пространственная составляющая:

- `y = A sin(t * f)`

где `A = verticalAmplitude`, `f = verticalFrequency`.

## Быстрый старт

1. Открой репозиторий как Unity-проект в Unity Hub (рекомендуется Unity `2022.3 LTS`).
2. Открой любую сцену (или создай новую пустую).
3. Запусти Play — bootstrap-скрипт автоматически создаст:
   - объект со спирографом,
   - камеру с орбитальным управлением,
   - источник света.
4. Меняй параметры в `Spirograph3DGenerator` и вызывай `Regenerate Spirograph` через контекстное меню компонента.

## Идеи для экспериментов

- Изучить, как влияет отношение `R/r` на замыкание траектории.
- Включить/выключить Y-модуляцию и сравнить визуальное восприятие глубины.
- Менять `sampleCount` и `tMaxMultiplier` для исследования гладкости и сложности кривой.
